## Bug 修复: sockjs-client `global is not defined`

### 问题
- 陪伴房页面打不开，浏览器报 `ReferenceError: global is not defined`
- 根因: `sockjs-client` 是 CommonJS 模块，内部使用 Node.js `global` 对象，浏览器环境无此全局变量
- `roomStore` 在模块顶层调用 `useWebSocket()` → 导入 `sockjs-client` → 整个模块链加载失败 → 白屏

### 修复 (双重保障)
1. `vite.config.ts` 添加 `define: { global: 'globalThis' }` — 构建时文本替换
2. `index.html` 添加 polyfill `<script>if (typeof global === 'undefined') { window.global = window; }</script>` — 运行时确保 `global` 定义
3. 清除 `node_modules/.vite` 缓存目录 + `npx vite --force` 重启

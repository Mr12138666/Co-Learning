四、设计方向

整体必须具有安静、专业、高密度的生产力工具气质：

- 紧凑但不拥挤
- 强调可扫描性和操作效率
- 低装饰、低噪音
- 克制使用卡片
- 页面区块尽量采用无边框布局、分割线和层级背景
- 卡片圆角不超过 8px
- 禁止大面积渐变、装饰光球、玻璃拟态和营销页风格
- 禁止满屏同一种深蓝色
- 禁止无意义的大标题和大块留白
- 禁止卡片套卡片
- 命令按钮使用图标或图标加短文本
- 使用项目图标库或 Lucide 图标，禁止用 Emoji 充当正式功能图标
- 所有陌生图标必须提供 Tooltip
- 深色和浅色主题都要完整设计
- 颜色不能是简单反色，必须分别校准对比度和层级

六、重点页面

1. 应用外壳

高保真参考 super-productivity 的桌面生产力布局：

- 固定或可折叠侧边栏
- 清晰的主导航分组
- 顶部工具栏
- 主内容区
- 全局快速开始专注入口
- 当前专注状态
- 用户和主题菜单
- 移动端抽屉或底部导航

导航折叠不能导致页面宽度跳动、文字溢出或图标偏移。

2. 首页工作台

改造成类似生产力工具的今日工作台：

- 今日日期和轻量标题
- 快速开始专注
- 今日目标与完成进度
- 今日任务列表
- 最近学习内容
- 当前或最近自习室
- 学习时长摘要
- 宠物状态作为次要激励信息

不要把每个数据都放进独立大卡片。

3. 学习内容、目标和任务

参考 super-productivity 的任务列表：

- 紧凑任务行
- 完成状态
- 科目颜色
- 标签
- 预计或实际时长
- 行内快捷操作
- Hover 时显示次要工具
- 筛选、排序和搜索
- 桌面端支持高效批量浏览
- 移动端保证触控区域

4. 专注计时

参考 Focus Mode 重构：

- 专注计时是第一视觉焦点
- 正计时、倒计时、番茄钟使用分段控件
- 科目和任务选择
- 开始、暂停、继续、结束
- 当前阶段和进度
- 8 小时限制和宽限期
- 退出专注模式的明确入口
- 防止按钮和动态文字导致布局跳动

5. 统计和排行榜

参考生产力统计界面：

- 安静、清晰的图表
- 日、周、月切换使用分段控件
- 学习时长、趋势、科目分布
- 排行榜强调排名和当前用户
- 图表颜色来自设计 Token
- 小屏幕不能横向溢出

6. 日志和每日复盘

参考 Notes 风格：

- 列表与详情层级清楚
- 编辑器工具栏紧凑
- 编辑/预览模式明确
- Markdown 内容排版专业
- 图片上传状态可见
- 草稿、公开状态和保存状态明确
- 禁止原始 `v-html` 内容未经安全处理

7. 自习室

采用生产力协作工具布局：

- 房间列表紧凑、易扫描
- 房间详情使用明确的主内容区和成员侧栏
- 聊天区、成员区和专注状态不互相抢占空间
- 房主操作集中在菜单或工具栏
- 在线、专注、离线状态清楚
- 移动端成员面板放入抽屉

8. 宠物和成就

保留趣味性，但不能脱离整体设计：

- 宠物本体是页面焦点
- 状态、经验、等级和操作层级明确
- 道具使用真实图标或图片
- 不使用 Emoji 代替资产
- 成就使用紧凑网格或列表
- 未解锁状态清楚，但不应过度灰暗

9. 登录注册

登录页必须有明确的 Co-Learning 产品信号：

- 不做营销落地页
- 表单居中且尺寸稳定
- 提供品牌名称、简洁标识和必要表单
- 测试账号只在开发环境显示
- 桌面端不能出现巨大无意义空白
- 移动端不能横向溢出

- 主 Agent 负责最终集成和视觉一致性检查
